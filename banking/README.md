# Banking Analyst Academy

A 40-lesson, 30-minutes-a-weekday course on how banks work and make money, built for a Data Analyst at BPI (Data Platforms / CEDA). It runs from beginner to advanced and is Philippines-focused (BSP rules, BPI public disclosures).

| Module | Lessons |
|---|---|
| 1 · How banks work | 1–5 |
| 2 · Products and business lines | 6–10 |
| 3 · Financial performance metrics (NII, NIM, CIR, asset quality, ROA/ROE) | 11–15 |
| 4 · Profitability measurement (FTP, cost allocation, account/product/customer/channel profitability, CLV, RAROC) | 16–21 |
| 5 · Risk and regulation | 22–25 |
| 6 · Banking data architecture (systems, warehouse/marts, MDM, GL reconciliation, governance, data quality, SSOT) | 26–31 |
| 7 · Stakeholders and analyst craft | 32–36 |
| 8 · Case studies and capstone | 37–40 |

- **Lessons:** the Notion page "Banking Analyst Academy" (database "Banking Lessons"). Source in `curriculum/` (`m1.py`–`m8.py`; `render.py` builds the pages; `test_sql.py` runs every SQL snippet against the sample database).
- **Practice data:** `data/` – see `data/README.md`.
- **Schedule and auto-shift:** `plan/` – see `plan/README.md`.

✅ boxes = publicly verified facts with a source link. 🧪 boxes and all sample data = illustrative, made-up numbers.
